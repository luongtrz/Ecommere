# User Shop

Backend và Frontend cho User Shop của hệ thống Thai Spray E-Commerce.

## 🎯 Features

- Product Browse & Search
- Shopping Cart
- Checkout & Payment
- Order Management
- User Profile
- Product Reviews

## 🚀 Quick Start

### Backend

```bash
cd backend
npm install
npm run start:dev
```

Port: 4000

### Frontend

```bash
cd frontend
npm install
npm run dev
```

Port: 5173

## 🔐 Local seed account

The destructive Prisma seed requires explicit `SEED_ADMIN_PASSWORD` and
`SEED_USER_PASSWORD` values. Choose local-only credentials when running it;
there are no production default credentials.
